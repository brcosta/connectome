# Changelog

All notable changes to Connectome are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-18

### Added

- Compact local MCP server for Java and Clojure symbol search, exact source retrieval, and bounded call tracing.
- Tree-sitter indexing with optional JDT LS and clojure-lsp semantic enrichment.
- Java overload selectors and Clojure multimethod dispatch edges.
- Reproducible native, codebase-memory, and Connectome benchmark harness.
- Cross-platform CI and tag-driven GitHub releases.
